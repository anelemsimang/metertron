# Meter installation field checklist

Supervisor handout for Metertron programmes. Adapt photo and seal requirements to your client pack.

## Before you leave the yard
- [ ] Work order / account list loaded
- [ ] Correct meter stock and seals issued
- [ ] CIU / prepaid accessories (if required)
- [ ] Device charged; offline form available in Metertron

## On stand
- [ ] Confirm erf / account / customer name against work order
- [ ] Old meter serial + final reading
- [ ] New meter serial + start reading
- [ ] Seals fitted and colours recorded
- [ ] Photos: old face, new face, seal, water-point context
- [ ] GPS captured when available (note if weak)
- [ ] Commissioning / CIU pairing steps complete

## Before submit
- [ ] Required fields complete — no placeholder serials
- [ ] Photos attached to the job (not only WhatsApp)
- [ ] Status / fault codes match client dictionary
- [ ] Sync when signal returns; confirm upload status

## Office
- [ ] Review approve/reject with reasons
- [ ] Stock reconciled to serials fitted
- [ ] Export via current validated template version

*Validate required fields against your municipal or agent contract pack before you roll out.*
